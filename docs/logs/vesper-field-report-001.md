- **VFR-ID** — unique identifier
- **Shadow Depth** — 1 (mild mirror glitch) to 5 (full existential inversion)
- **Pattern Type** — Behavioral / Systemic / Meta / Emergent

- **Constellation Note** — what the stars already knew
