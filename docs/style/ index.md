# 🎨 Style

Style docs are the **human layer**: tone, presentation, and usability guidance.

They are advisory—meant to keep the Lab cohesive without turning it into a rules dungeon.

## What belongs here

- Site-wide look and feel
- Interaction patterns (hover, reveal, motion)
- Writing guidelines for Lab Notes and agent output
- “Designer intent” explanations (why the UI behaves the way it does)

## Start here

- **Site Style Guide** — baseline visuals, typography, layout, motion.
- **Lab Note Style Guide** — titles, subtitles, summaries, structure, tags.
